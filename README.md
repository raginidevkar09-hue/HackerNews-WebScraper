# Hacker News Web Scraper (BeautifulSoup)

This project scrapes real-time news data from Hacker News (https://news.ycombinator.com) using Python and BeautifulSoup.

## Extracted Data
The scraper collects:
- News Title
- Article Link
- Author
- Points (upvotes)
- Number of Comments
- Time Posted
- Story ID

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Jupyter Notebook

## Output Files
- data.csv
- data.json

## Features
- Handles pagination
- Extracts structured data
- Stores data in CSV and JSON formats

## How to Run
Open the Jupyter notebook and run all cells. The CSV and JSON files will be generated automatically.

This project is built for academic and learning purposes.
